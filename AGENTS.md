# Course maintenance schema

This file documents the artifact for future maintenance. Preserve source provenance and distinguish extracted textbook material from authored learning tools.

- `raw/chapters`: chapter text with PDF and printed page markers; original source numbering.
- `wiki/chapters`, `wiki/flashcards`, `wiki/mcqs`: source-linked study material.
- `wiki/parts`: editorial study pathways, not book part divisions.
- `data/course.js`: generated study catalog; `data/chapters`: lazy-loaded reader payloads.
- `figures`, `tables`: original image crops and table/page renderings.
- `build`: scripts, source metadata, metrics, verification results, and documented extraction state.

Do not describe automated passage recognition as independently authored board questions. Preserve age, route, dose units, maxima, and source context in any treatment edit. Run source and browser checks after substantive changes. External publication requires a separate explicit user request.
